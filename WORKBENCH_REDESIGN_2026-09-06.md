## Defined boundaries

- Fractional element splitting applies to Frame line members. Surface topology remains generated by meshing.
- Regenerating a surface mesh applies the default thickness section to its new elements; review individual assignments after remeshing.
- A saved project is limited to 20 MB. Only terminal analysis records are archived; in-progress jobs are omitted. Saving without results remains available.
- Account snapshots require authentication and retain existing user isolation. Guests can download portable project files.
- Import and account saving validate model/result fingerprints and Section/materialized-property consistency. Existing model JSON and restart imports remain supported.
- The engineering workbench keeps a 1120px minimum width; narrower windows scroll rather than compressing the canvas and inspector into unusable columns.
