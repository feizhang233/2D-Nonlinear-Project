# 验证矩阵

## 1. 状态定义

- `理论基准已整理`：本包已有可核对的解析/算法答案；
- `实现通过`：未来某一代码版本实际运行通过，且保存了输入和证据；
- `阻塞`：缺少模型、数据、依赖或明确边界；
- 当前所有题仅为 `理论基准已整理`，不得自动升级为 `实现通过`。

## 4. 实现证据元数据

未来把任何项标为“实现通过”时，至少记录：

- 代码版本/commit；
- 模型文件和输入哈希；
- 单位、材料、厚度、载荷和边界；
- 元素类型、积分和网格统计；
- 正号、约束和模态归一化；
- 求解器、容差、迭代上限和线性代数后端；
- 特征值残量、MAC/子空间和网格序列；
- 缺陷幅值、符号、法向和应用后几何；
- 弧长参数、步长、拒绝步、回滚和路径；
- 实际误差、通过阈值和失败说明。
