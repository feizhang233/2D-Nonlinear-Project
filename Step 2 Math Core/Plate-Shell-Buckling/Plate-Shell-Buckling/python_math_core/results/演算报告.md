# Plate-Shell Buckling Python 数学核心演算报告

## 分析层级与正号约定

- 平衡：`r(q, λ) = f_int(q) - λ f_ref = 0`。
- LBA：`K_M φ = λ K_G φ`，且 `K_G = -K_σ,ref`；压缩膜力取正。
- 线性特征值仅表示完美基本路径上的局部中性倍率，不是设计强度。
- GNA 弧长收敛表示增广方程找到平衡点，不证明分支稳定或唯一。
