# 壳体失稳算法局限与适用边界

## 1. 线性特征屈曲的边界

线性特征值只描述完美基本路径附近的局部中性条件。它通常不包含：

- 缺陷诱发的屈曲前弯曲；
- 后屈曲软化和真实极限点；
- 材料屈服、损伤、残余应力和厚度偏差；
- 接触、间隙、载荷引入细节和边界柔度；
- 制造缺陷的散布和概率尾部。

因此，线性特征值是验证和模态信息，不自动等于极限承载力或设计值。

## 2. 临界点分类的边界

`K_T` 奇异不等于“已经证明分岔”。分类还依赖：

- 载荷参数化是否完整；
- 左零向量与载荷导数的投影；
- 临界零空间维数；
- 约束和刚体模式是否正确清除；
- 切线是否对称、保守和一致。

若存在 follower load、摩擦或其他非保守项，右特征向量不能替代左特征向量，势能正定性也可能不再适用。

## 3. 弧长法的边界

弧长法解决的是路径参数化问题，不自动解决：

- 错误残量或错误切线；
- 多解中的物理分支选择；
- 动态跳跃后的真实响应；
- 接触状态突变和材料局部化；
- 过大步长跨过的尖锐分岔或局部极限点。

得到一条收敛路径，不代表该路径稳定、唯一或实验可实现。步长、根选择、预测方向和状态回滚都必须验证。

## 4. Koiter 渐近的边界

Koiter 约化是临界点邻域的小幅值展开：

- 离临界点较远时，高阶遗漏可能主导；
- `A3/A4` 对模态归一化和导数实现敏感；
- 单模态结论只适用于孤立临界模态；
- 多模态时必须保留交叉张量和二阶修正场；
- 局部幂律不能覆盖有限缺陷、接触和塑性主导的路径。

约化模型应与全阶非线性路径在逐渐缩小的临界邻域内对比，不能只拟合一条远场曲线。

## 5. 模态交互与模态跟踪的边界

- 特征向量有任意符号；周期/复模态还有相位自由度；
- 重根空间内的基可任意旋转，逐模态 MAC 可能误导；
- 网格、边界和数值扰动会交换模态排序；
- 预选太少模态会漏掉危险混合方向；
- 预选太多且无间隙控制会使约化系统病态。

模态簇阈值没有通用常数，应通过相对间距、子空间稳定性和结果敏感性共同确定。

## 6. 缺陷敏感性的边界

模态型缺陷只是研究族之一。实际最危险缺陷可能是：

- 局部凹陷；
- 多波数组合；
- 焊缝、接头和厚度偏差耦合；
- 实测非平稳缺陷场；
- 与边界、残余应力或载荷偏心协同的缺陷。

把第一线性模态缩放为 `alpha*h` 不能代表全部制造误差。最危险方向还可能随缺陷幅值改变。

## 7. 分支切换的边界

特征向量扰动后 Newton 收敛可能：

- 回到基本分支；
- 收敛到另一条并非目标的分支；
- 因对称性得到等价副本；
- 因种子过大跳出临界邻域；
- 因种子过小被容差吞没。

分支身份需要相位/正交约束、模态投影、反向连续、不同种子和网格复核。重根下应先在约化幅值空间求候选方向。

## 8. 壳单元与网格边界

失稳结果对离散特别敏感：

- 剪切/膜/体积/曲率锁定可能制造假刚度；
- 钻孔自由度和稳定化可能污染低特征值；
- 几何映射、法向更新和厚度积分错误会污染几何刚度；
- 半波解析不足会系统性高估临界值；
- 网格不规则、畸变和对称性可能改变模态簇。

经典短波尺度约为 `O(sqrt(Rh))`。讲义中的“每半波约 6-10 个低阶单元”是起始检查，不是通用收敛证明。

## 9. 材料和状态边界

GMNIA 需要材料返回一致算法切线并遵守 trial/commit/rollback。否则：

- 失败迭代会污染塑性/损伤历史；
- 切线惯性和极限点位置不可信；
- 步长缩减后路径不可重复；
- 约化能量可能不再有保守系统的直接解释。

本包没有提供完整塑性、损伤、黏性、接触或断裂模型。

## 10. 边界、载荷和实验边界

薄壳失稳常受端部环、夹具、摩擦、载荷引入长度和局部刚度控制。理想简支/固支标签不足以描述实验。工程比较至少要记录：

- 平移和转动的实际约束刚度；
- 载荷是否均匀、偏心或 follower；
- 端部加厚、焊接和接头；
- 测得几何、厚度和残余应力；
- 试验控制方式和动态跳跃。

## 11. 数值阈值边界

残量容差、特征值簇阈值、MAC 阈值、弧长步长、缺陷幅值和网格密度都没有对所有模型有效的统一数值。阈值必须：

1. 无量纲化；
2. 记录来源；
3. 做至少一个数量级的敏感性或收敛检查；
4. 与物理量和线性求解误差同时解释。

## 12. 研究结论分级

| 层级 | 能回答 | 不能直接回答 |
|---|---|---|
| L1 线性屈曲 | 理想中性载荷、模态和网格/边界趋势 | 缺陷后极限载荷、后屈曲稳定性 |
| L2 完美 GNA | 完美路径、极限点和分岔候选 | 制造缺陷散布、材料失效 |
| L3 GNIA | 指定缺陷族的折减和危险方向 | 塑性、残余应力和概率尾部 |
| L4 GMNIA | 指定材料/缺陷/边界模型下的工程极限路径 | 模型外风险、规范安全系数、可靠度 |
| 实验/统计 | 标定和散布证据 | 未覆盖工况的自动外推 |

任何结论都应明确自己停在哪一级。
