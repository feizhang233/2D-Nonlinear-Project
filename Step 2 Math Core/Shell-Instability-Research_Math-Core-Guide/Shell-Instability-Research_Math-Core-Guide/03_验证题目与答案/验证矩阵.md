# Shell Instability Research 验证矩阵

## 1. 固定顺序

一致切线 -> 临界分类 -> 线性屈曲 -> 单模态约化 -> 多模态交互 -> 缺陷 -> 弧长 -> 分支切换 -> 壳解析基准 -> 端到端研究。前层失败时，后层“曲线平滑”不能作为补偿。

## 2. 必做测试

| ID | 层级 | 测试 | 主要故障 | 最低验收条件 |
|---|---|---|---|---|
| V00 | 代数/切线 | 中心方向差分 | 内力、几何或装配切线缺项 | `Kp=(0.202,-0.744)`；扫描 `h` 呈二阶区和误差谷值 |
| V01 | 临界分类 | 左零向量投影 | 把奇异点一律叫分岔点 | A 为极限点，B 为分岔候选；说明左/右向量边界 |
| V02 | 线性屈曲 | 2DOF 广义特征值 | 符号、预应力、约束或特征值排序 | `lambda=(7.1494134,20.6766736)`，模态残差接近舍入级 |
| V03 | 单模态 Koiter | 超/次临界 | A4 符号或 Hessian 解释错误 | 两分支幅值 `0.316228`；Hessian `+0.8/-0.8` |
| V04 | 模态交互 | 双模态混合分支 | 忽略交叉项、把单模态稳定性当全空间稳定性 | 混合分支能量 `-0.0133333`；Hessian 特征值均正 |
| V05 | 缺陷渐近 | 2/3 尺度律 | 幂指数、归一化或多模态误用 | 三个 `lambda*` 匹配答案；对数斜率 `2/3` |
| V06 | 路径跟踪 | 一自由度球形弧长 | 预测、根选择、增广校正 | 校正点 `(0.5995912434,0.3840323999)`；残量/约束同时为零 |
| V07 | 分支切换 | 正交种子 | 把种子当已收敛分支 | `gamma=-1`、种子 `(0,-1)`；列出全阶校正证据 |
| V08 | 圆柱壳 | 经典轴压基准 | 单位、波数、网格半波不足 | `sigma_cr=85.625710 MPa`、`P_cr=269.001102 kN` |
| V09 | 球壳 | 经典外压基准 | 膜力/压力混淆、理想值工程化 | `p_cr=0.34250284 MPa`、`N=85.625710 N/mm` |
| V10 | 研究门槛 | GNIA/GMNIA 审查 | 单一 eigenvalue/曲线替代完整证据 | 八类证据全部具备；结论明确停在 L1-L4 哪一级 |

## 3. 合并门槛

- 核心公式或代码改动：V00-V09；
- 多模态/缺陷/分支算法改动：必须包含 V04、V05、V07；
- 壳单元或网格改动：必须包含 V00、V02、V08、V09；
- 研究或工程结论：必须完成 V10，并提供真实模型的网格、步长、边界和缺陷矩阵。

## 4. 建议自动化元数据

- 软件版本、提交号、线性代数后端；
- 单位、模型、网格、元素、积分、稳定化；
- 边界、载荷参数化、预应力来源；
- 残量符号、一致切线和方向差分数据；
- 特征值、奇异值、惯性、左右模态和归一化；
- 模态簇、MAC、主夹角和模态投影；
- 弧长、步长、`beta`、根选择和失败回滚；
- 缺陷场、幅值、符号、方向、位置和随机种子；
- 参考值、误差定义、容差和接受结论。
