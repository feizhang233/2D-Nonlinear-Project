# Shell Instability Research 数学核心引导

## 1. 目标

本文件夹把当前工作区与壳体失稳研究直接相关的成品讲义、基础屈曲讲义、原书、可复现脚本和新增 AI 索引集中到一个独立资料包。主线覆盖：

- 极限点与分岔点的检测和分类；
- 单模态与多模态 Koiter 约化；
- 模态交互、模态簇和模态跟踪；
- 初始缺陷敏感性及 `1/2`、`2/3` 尺度律；
- 弧长路径跟踪与分支切换；
- 圆柱壳、球壳和低维模型验证；
- 8-12 周研究训练路线。

## 4. 完成边界

本资料包现包含“可检索研究知识包”和通过 V00-V10 的低维 Python 数学核心，但不是完整有限元代码实现。它给出算法契约、验证题、可执行基准和研究证据门槛，但不能替代：

- 非线性壳单元的一致线性化和实现；
- 材料、接触、残余应力和制造缺陷的标定；
- 实验或规范安全系数；
- 对具体结构的工程签审。
