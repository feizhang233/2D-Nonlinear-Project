# Python 数学核心与验证

## 1. 实现目标

本目录把资料包中的数学链转成可执行、可测试的 Python 核心：

```text
R(q,lambda) 与一致切线
  -> 切线奇异性和左右零向量分类
  -> 线性广义特征屈曲
  -> 单/双模态 Koiter 约化与缺陷律
  -> 球形弧长路径跟踪和分支种子
  -> 圆柱壳/球壳解析基准
  -> V00-V10 自动验收与证据报告
```

残量统一采用：

$$
\mathbf R(\mathbf q,\lambda)
=\mathbf f_{int}(\mathbf q)-\lambda\mathbf f_{ref}=\mathbf 0.
$$

代码中的 Newton、弧长和临界点分类均按这一符号约定实现。

## 2. 代码路由

| 模块 | 数学对象 | 对应验证题 |
|---|---|---|
| `differentiation.py` | 中心方向差分、误差阶次与误差谷值 | V00 |
| `critical.py` | 奇异值、惯性、左右零向量投影、MAC、子空间主夹角 | V01、模态簇支持 |

| `audit.py` | GNIA/GMNIA 研究证据八类门槛 | V10 |

## 3. 运行

在本目录执行：

```bash
python3 -m unittest discover -s tests -v
python3 run_validation_problems.py
```

第二条命令会生成：

- `output/V00-V10_演算结果.md`：人可读的逐题演算；
- `output/V00-V10_演算结果.json`：机器可读的数值、误差和验收状态。

只依赖 Python 3.10+ 和 NumPy，不需要 SciPy 或 pytest。

## 4. 输入—处理—输出契约

- 输入必须显式给出单位、残量符号、载荷参数化、边界/约束后矩阵以及模态归一化。
- 数值处理必须同时保留平衡残量、特征残差、弧长约束误差或方向差分误差，不能只返回一个载荷数字。
- 输出区分线性特征值、切线奇异点、极限点、分岔候选点和含缺陷极限载荷；这些名称不可互换。
- 临界点分类必须先通过切线奇异值、单一零空间及左右零向量残差检查；非对称切线还必须显式提供左零向量。
- 重根/近重根不能调用单模态分类接口，应使用临界子空间和主夹角，不依赖单个模态编号。
- V10 的每个最低要求必须提供证据定位、验收准则、实际观测和通过状态；类别布尔值不构成研究证据。

V10 单项证据记录形式为：

```python
from shell_instability_math import EvidenceRecord

record = EvidenceRecord(
    artifact="results/tangent_scan.json",
    acceptance_criterion="方向差分在截断误差区呈二阶收敛",
    observed="h=1e-1 至 1e-3 的相邻阶次约为 2.0",
    accepted=True,
)
```

## 5. 已实现边界

这套代码是资料包算法的低维可执行参考与回归测试，不是完整有限元程序：

- 没有实现壳单元运动学、内力、几何刚度或一致材料切线；
- 没有实现大转动、材料塑性/损伤、接触、残余应力或制造缺陷场；
- 弧长核心不管理材料历史状态，接入真实材料时调用层必须实现 `trial/commit/rollback`；
- 广义特征基准使用 NumPy Cholesky 变换，要求 `K_G` 对称正定；真实稀疏/不定问题需使用经验证的专用求解器；
- Koiter 结果只在临界点邻域有效；2/3 律不能替代多模态缺陷方向扫描；
- V08/V09 是理想经典基准，不是设计值或真实承载力。
