# 五周总览与材料点接口

## 1. 学习与实现依赖

```text
W10 状态与热力学约束
  -> W11 一维后向欧拉和局部残量
    -> W12 3D J2 径向返回
      -> W13 离散一致切线和 plane-stress 凝聚
        -> W14 组合硬化循环历史
          -> 材料点回归
            -> 单元积分点
              -> 全局 Newton + commit/rollback
```

任一后续层失败时，先回退到前一层最小验证；不要直接在全局有限元算例中调材料公式。

## 2. 材料点唯一规范接口

材料点更新应是一个对 committed state 无副作用的映射：

$$
(\boldsymbol\varepsilon_{n+1},\mathcal S_n,\mathcal P)
\longmapsto
(\boldsymbol\sigma_{n+1},\mathbb C^{alg}_{n+1},
\mathcal S^{trial}_{n+1},\mathcal D_{n+1}),
$$

其中：

- `epsilon_(n+1)`：目标总应变；
- `S_n`：上一个已接受步的 committed material state；
- `P`：材料参数和数值选项；
- `sigma_(n+1)`：与目标应变相容的更新应力；
- `C_alg`：离散更新映射对目标应变的导数；
- `S_trial`：候选状态，只能在全局收敛后提交；
- `D`：分支、局部残量、迭代次数和失败原因。

若代码接口输入 `Delta_epsilon` 而非总应变，必须同时明确其参考应变和 committed state；不得混用两种接口。

## 3. 职责边界

| 层级 | 负责 | 不负责 |
|---|---|---|
| 材料点 | 应力更新、内部变量、局部一致切线、局部诊断 | 全局荷载步接受、边界条件、全局残量 |
| 单元/积分点 | 运动学、`B` 矩阵、积分权重、内力和材料切线装配 | 擅自提交材料状态 |
| 全局求解器 | Newton、控制、线搜索、步长、收敛、commit/rollback 调度 | 直接改写材料历史变量 |

## 4. 规范事务流程

```text
state_n = committed_state.copy()

for each global trial iteration:
    for each integration point:
        stress, C_alg, trial_state, diag = material.update(
            total_strain_np1,
            state_n,           # 每次均为同一 committed state
            parameters,
        )
        if local update failed:
            reject global trial
    assemble internal force and tangent from current trial outputs
    solve global correction

if global step converged:
    committed_state = deep_copy(all trial_states)
else:
    discard all trial_states
    reduce step and restart from state_n
```

局部材料点可以在一次调用内部进行 Newton，但不得跨全局迭代累加尚未接受的塑性变量。

## 5. 参数、状态与诊断的最小模式

### 参数

| 字段 | 含义 | 单位 |
|---|---|---|
| `E` | Young 模量 | stress |
| `nu` | Poisson 比 | 1 |
| `sigma_y0` | 初始屈服应力 | stress |
| `H_iso` | 线性各向同性硬化模量 | stress |
| `H_kin` | 一维线性随动硬化模量 | stress |
| `Q` | Voce 饱和硬化幅值 | stress |
| `b` | Voce 饱和速率参数 | 1 |
| `H_linear` | Voce 模型附加线性硬化模量 | stress |
| `yield_tolerance` | 屈服判定绝对/相对容差 | stress 或无量纲 |
| `local_tolerance` | 局部残量容差 | 与残量同量纲 |
| `max_local_iterations` | 局部迭代上限 | 1 |

线性 J2 与 Voce J2 应使用不同参数模式：线性模型使用 `H_iso`，Voce 模型使用 `Q, b, H_linear`。除非另行定义叠加模型，不得把未使用的 `H_iso` 静默保留在 Voce 参数对象中。

### Committed state

| 字段 | 规范模型 |
|---|---|
| `plastic_strain` | 1D 标量或 3D 对称张量 |
| `alpha` | 累积等效塑性应变，单调不减 |
| `backstress` | W14 一维组合硬化需要；纯各向同性 J2 不需要 |

### Diagnostics

| 字段 | 验收意义 |
|---|---|
| `branch` | `elastic` / `plastic` / `failed` |
| `f_trial` | 是否进入塑性校正 |
| `delta_gamma` | KKT 要求塑性分支非负 |
| `yield_residual` | 更新点是否回到离散屈服面 |
| `local_iterations` | 局部迭代和切步依据 |
| `tangent_kind` | `elastic` / `algorithmic_consistent` / 其他 |
| `convention` | tensor 或具体 Voigt 排列/剪切定义 |

## 6. 实现顺序和停止条件

1. 先实现一维弹性分支与 V00。
2. 加入一维线性硬化闭式返回，完成 V01-V02。
3. 实现 3D J2 张量更新，完成 V03-V05。
4. 实现解析算法切线，完成 V06 后才接全局 Newton。
5. 实现 trial/commit/rollback，完成 V07。
6. 加入一维组合硬化循环路径，完成 V08。
7. 需要二维连续体时，再实现 plane-stress 外层局部约束并完成 V09。
8. 需要非线性硬化时，增加有保护的局部 Newton 并完成 V10。
9. 最后用 V11 连接材料点与全局 Newton。

任何 `Delta_gamma < 0`、更新后屈服残差超限、`alpha` 减小、非有限数、局部 Newton 未收敛或 committed state 被 trial 修改，均应立即把本次材料调用标记为失败。
