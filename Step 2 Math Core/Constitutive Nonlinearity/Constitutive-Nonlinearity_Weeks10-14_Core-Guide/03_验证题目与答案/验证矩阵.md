# Constitutive Nonlinearity 验证矩阵

## 1. 分层顺序

```text
标量弹性/塑性
  -> 3D 张量不变量
    -> J2 返回与耗散
      -> 一致切线方向导数
        -> 状态事务
          -> 循环历史
            -> plane-stress 局部约束
              -> 非线性硬化局部 Newton
                -> 全局材料耦合
```

## 5. 方向导数标准流程

1. 固定 committed state 和材料参数。
2. 选择远离分支切换面的塑性目标点。
3. 对每个 `h`，分别从同一 state 计算正负扰动。
4. 验证两侧仍为预期分支。
5. 比较完整应力张量或明确 Voigt convention 的向量。
6. 记录误差、误差比和最小误差；不要只保留“通过”。
7. 若误差先下降后上升，识别舍入误差区间；若不下降，检查切线、状态和剪切映射。

## 6. 路径回归规则

- 循环题逐点比较，不只比较最后一点。
- `alpha` 必须单调不减。
- 弹性卸载段 `epsilon_p/alpha/X` 保持。
- 屈服转折附近做路径子步减半；状态和反向屈服位置应收敛。
- 被拒绝步必须保留诊断但不得进入下一 committed history。
