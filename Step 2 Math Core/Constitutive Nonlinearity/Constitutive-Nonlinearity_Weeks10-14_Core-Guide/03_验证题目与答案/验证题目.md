# Constitutive Nonlinearity 验证题目

## 使用规则

- 先独立完成题目，再读取 `配套答案.md`。
- 除非题目另有说明，应力单位为 MPa，应变无量纲。
- J2 题使用 3x3 真张量，双点积为 Frobenius 内积。
- 每个扰动或被拒绝试算都必须从题目给定的同一 committed state 重算。
- 数值参考可由 `../04_可复现算例/reference_material_point.py` 独立生成。

## V00 - 弹性分支与零状态

一维材料参数：

```text
E = 210000
sigma_y0 = 250
H_iso = 1000
H_kin = 0
state_0 = {epsilon_p=0, alpha=0, X=0}
epsilon_1 = 0.001
```

求应力、分支、算法切线和候选状态。说明 committed state 是否允许被修改。

## V01 - 一维线性硬化闭式返回

使用 V00 参数和 virgin state，施加：

```text
epsilon_1 = 0.002
```

求：

1. `sigma_trial` 与 `f_trial`；
2. `Delta_gamma`；
3. `epsilon_p_1`、`alpha_1`、`sigma_1`；
4. 塑性分支算法切线；
5. 更新后屈服残差。

## V02 - 弹性卸载和状态保持

从 V01 的状态出发，把总应变改为：

```text
epsilon_2 = 0.001
```

求应力、分支、切线和内部变量。解释为何 `alpha` 不应减少。

## V03 - J2 静水不变性

3D 参数：

```text
E = 210000
nu = 0.3
sigma_y0 = 250
H_iso = 1000
state_0 = {epsilon_p=0_3x3, alpha=0}
epsilon_1 = 0.001 I
```

求 `K`、应力张量、`q_trial`、分支和 `alpha_1`。说明这个题验证了 J2 的什么性质。

## V04 - 3D J2 单步径向返回

使用 V03 参数和 virgin state，施加：

$$
\boldsymbol\varepsilon_1=
\begin{bmatrix}
0.002&0&0\\
0&0&0\\
0&0&0
\end{bmatrix}.
$$

求：

1. `G`、`K`；
2. trial 应力、`p_trial`、`q_trial` 和 `f_trial`；
3. `Delta_gamma`；
4. 更新应力主对角、`q_1` 和 `alpha_1`；
5. 更新后屈服残差。

## V05 - 塑性不可压缩、KKT 与耗散

沿用 V04，计算：

1. `trace(Delta_epsilon_p)`；
2. `Delta_gamma` 的符号；
3. `alpha_1-alpha_0`；
4. 简化理想塑性耗散项 `sigma_y0 * Delta_gamma`；
5. 如果 `f_trial < 0` 却更新了 `alpha`，违反了哪些条件。

## V06 - 一致切线方向导数

沿用 V04 的 virgin committed state 与目标应变。令：

$$
\mathbf D_0=
\begin{bmatrix}
0.6&0.2&0\\
0.2&-0.1&0\\
0&0&0.3
\end{bmatrix},
\qquad
\mathbf D=\frac{\mathbf D_0}{\|\mathbf D_0\|_F}.
$$

对：

```text
h = [2e-5, 1e-5, 5e-6, 2.5e-6, 1.25e-6, 6.25e-7]
```

计算中心差分应力方向导数，与 `C_alg : D` 比较。报告每个 `h` 的相对误差、相邻误差比，并判断是否显示二阶趋势。正负扰动都必须从 virgin committed state 重算。

## V07 - Trial / rollback / commit

先把 V01 状态视为 committed state `S_1`。

1. 从 `S_1` 对 `epsilon=0.003` 做一次候选更新，但拒绝该全局试算；
2. 再从 `S_1` 对 `epsilon=0.001` 更新；
3. 与未做第 1 步时从 `S_1` 直接更新的结果比较；
4. 列出实现中必须保存的回滚证据。

若第 2 步的应力或状态依赖被拒绝试算，判为失败。

## V08 - 组合硬化循环历史

一维参数：

```text
E = 200000
sigma_y0 = 250
H_iso = 1000
H_kin = 9000
state_0 = {epsilon_p=0, alpha=0, X=0}
strain_history = [0, 0.002, 0, -0.002, 0, 0.002]
```

逐步求：

- stress；
- elastic/plastic branch；
- `Delta_gamma`；
- `epsilon_p`、`alpha`、`X`；
- 当前算法切线。

再由第一次正向峰值后的状态，求弹性反向加载的屈服应力和屈服总应变。

最后把每个相邻目标应变段等分为 2 个子步并重新积分，比较 6 个原路径端点的应力、`epsilon_p`、`alpha` 和 `X`；报告粗路径与细化路径的最大端点差异。

## V09 - 平面应力局部约束

使用 V03 的 J2 参数和 virgin state，给定面内总应变：

$$
\boldsymbol\varepsilon_{in}=
\begin{bmatrix}
0.002&0\\
0&0
\end{bmatrix}.
$$

以 `epsilon_zz` 为局部未知量，反复从同一 virgin state 调用 3D 更新，求满足 `sigma_zz=0` 的解。

报告：

- `epsilon_zz`；
- `sigma_xx`、`sigma_yy`、`sigma_zz`；
- `alpha`；
- 局部 Newton 次数；
- 平面应力切线的 Schur 凝聚公式。

再选任一不跨分支的对称面内方向，对凝聚切线执行与 V06 相同的多步长中心差分检查。

## V10 - Voce 非线性硬化局部 Newton

使用 V03 的 `E, nu, sigma_y0` 和 virgin state，硬化为：

$$
R(\alpha)=100[1-\exp(-15\alpha)]+500\alpha.
$$

施加：

$$
\boldsymbol\varepsilon_1
=\operatorname{diag}(0.003,0,0).
$$

建立标量局部残量，使用有非负区间保护的 Newton 求 `Delta_gamma`。报告：

- `Delta_gamma` 与局部迭代次数；
- 更新应力对角和 `q`；
- `R'(alpha_1)`；
- 更新后屈服残差。

## V11 - 材料点与全局 Newton 的一自由度连接

考虑 `L=1, A=1` 的一维杆，位移 `u` 即总应变。材料使用 V08 参数，但每个全局试算均从 virgin committed state 更新。目标外力等价为：

```text
target_stress = 260
u_0 = 0
```

采用：

$$
r=\sigma_{target}-\sigma(u),
\qquad
\Delta u=\frac{r}{C^{alg}}.
$$

列出每次迭代的 `u, sigma, r, C_alg`，并求最终位移。说明若始终使用弹性切线，对收敛速度有何影响。
