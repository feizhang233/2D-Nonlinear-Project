# Constitutive Nonlinearity 配套答案

所有参考值均由 `04_可复现算例/reference_material_point.py` 独立重算。显示位数不代表验收必须逐字符相等，应使用验证矩阵中的容差。

## V00 - 弹性分支与零状态

试算应力：

$$
\sigma^{tr}=210000(0.001)=210\ \text{MPa}.
$$

`f_trial = 210-250 = -40 MPa`，因此：

```text
branch = elastic
stress = 210 MPa
C_alg = 210000 MPa
candidate = {epsilon_p=0, alpha=0, X=0}
```

材料函数不得原地修改 committed state；弹性候选状态可复制或安全共享不可变对象。

## V01 - 一维线性硬化闭式返回

```text
sigma_trial = 420 MPa
f_trial = 170 MPa
```

$$
\Delta\gamma
=\frac{170}{210000+1000}
=0.0008056872037914692.
$$

因此：

```text
epsilon_p_1 = 0.0008056872037914692
alpha_1     = 0.0008056872037914692
sigma_1     = 250.80568720379148 MPa
C_alg       = 995.260663507109 MPa
```

更新后：

```text
abs(sigma_1) - (250 + 1000 alpha_1) = 0
```

到浮点容差。

## V02 - 弹性卸载和状态保持

从 V01 状态：

$$
\sigma^{tr}=210000(0.001-0.0008056872037914692)
=40.80568720379148\ \text{MPa}.
$$

该点在扩大的屈服区间内，故：

```text
branch = elastic
stress = 40.80568720379148 MPa
C_alg = 210000 MPa
epsilon_p = 0.0008056872037914692
alpha = 0.0008056872037914692
```

`alpha` 是累积塑性流动，弹性卸载时 `Delta_gamma=0`，不能减少。

## V03 - J2 静水不变性

```text
G = 80769.23076923077 MPa
K = 175000 MPa
trace(epsilon) = 0.003
```

纯静水应力：

$$
\boldsymbol\sigma=K\operatorname{tr}(\boldsymbol\varepsilon)\mathbf I
=525\mathbf I\ \text{MPa}.
$$

偏应力为零，所以：

```text
q_trial = 0
branch = elastic
alpha_1 = 0
```

该题验证 J2 对静水压力不敏感，不能用它描述围压改变屈服的材料。

## V05 - 塑性不可压缩、KKT 与耗散

V04 的流动方向为偏量，因此：

```text
trace(Delta_epsilon_p) = -1.63e-19 ~= 0
Delta_gamma = 0.00030034777110338293 > 0
alpha_1 - alpha_0 = Delta_gamma
sigma_y0 * Delta_gamma = 0.07508694277584574 MPa
```

最后一项为单位体积能量量纲。若 `f_trial<0` 仍增加 `alpha`，将违反 `f<=0, Delta_gamma>=0, Delta_gamma*f=0` 的互补条件，并使弹性路径产生伪耗散。

## V07 - Trial / rollback / commit

对 `epsilon=0.003` 的候选更新必须被丢弃。随后从原 `S_1` 更新到 `epsilon=0.001`，结果必须与 V02 完全一致：

```text
stress = 40.80568720379148 MPa
epsilon_p = 0.0008056872037914692
alpha = 0.0008056872037914692
committed_unchanged = true
```

最低回滚证据：

- rejected step/iteration ID；
- trial 输入应变和候选状态摘要；
- 拒绝原因；
- 回滚前后 committed state 哈希或逐变量相等检查；
- 重试步长和重试结果。

## V09 - 平面应力局部约束

使用弹性平面应力估计作为初值，并在每次局部迭代从同一 virgin state 重算，参考脚本在 5 次迭代内得到：

```text
epsilon_zz = -0.0012435578687300603
sigma_xx = 287.0710462143973 MPa
sigma_yy = 110.06107270232101 MPa
sigma_zz = 0.0 MPa
alpha = 0.0008542963771601343
```

平面应力算法切线为收敛 3D 算法切线的 Schur 凝聚：

$$
\mathbb C^{ps}_{ab}
=\mathbb C^{3D}_{ab}
-\mathbb C^{3D}_{az}
(\mathbb C^{3D}_{zz})^{-1}
\mathbb C^{3D}_{zb}.
$$

参考脚本对归一化面内方向

$$
\mathbf D_{in}\propto
\begin{bmatrix}0.7&0.15\\0.15&-0.2\end{bmatrix}
$$

得到的凝聚切线中心差分误差应随 `h` 减半约缩小 4 倍，最小步长误差低于 `1e-6`。这同时验证厚度应变的隐式导数，而不只验证 `sigma_zz=0`。

实际多步长结果为：

| `h` | relative error | 前一误差 / 当前误差 |
|---:|---:|---:|
| `2.0e-5` | `9.4968170493e-5` | - |
| `1.0e-5` | `2.3740355639e-5` | `4.0002842391` |
| `5.0e-6` | `5.9349835786e-6` | `4.0000709900` |
| `2.5e-6` | `1.4837392655e-6` | `4.0000178715` |
| `1.25e-6` | `3.7093479830e-7` | `4.0000001949` |

收敛点的 `C_zzzz = 197311.1663463256 MPa`，凝聚通过

$$
\mathbb C^{ps}_{ab}
=\mathbb C^{3D}_{ab}
-\mathbb C^{3D}_{az}(\mathbb C^{3D}_{zz})^{-1}\mathbb C^{3D}_{zb}
$$

显式计算，而不是通过给三维方向人为补一个固定 `epsilon_zz`。

把 3D 结果的 `sigma_zz` 直接置零不会得到相同的面内应力或状态。

## V10 - Voce 非线性硬化局部 Newton

局部残量为：

$$
g(\Delta\gamma)
=q^{tr}-3G\Delta\gamma
-250-R(\Delta\gamma).
$$

受保护 Newton 的参考结果：

```text
Delta_gamma = alpha_1 = 0.0009603697236943074
local_iterations = 2
R'(alpha_1) = 1978.5465763553907 MPa
q_1 = 251.91041310484098 MPa
sigma diagonal = [692.9402754032272,
                  441.02986229838626,
                  441.02986229838626] MPa
yield_residual = 1.99e-11 MPa
```

Python 实现使用独立的 `VoceJ2Parameters(E, nu, sigma_y0, Q, b, H_linear)`；线性 J2 的 `H_iso` 不进入本题，也不会被接口静默忽略。

解析切线应使用收敛点 `R'(alpha_1)`，而不是初始斜率或割线。

## V11 - 材料点与全局 Newton 的一自由度连接

采用 `r = target - sigma` 和 `Delta u = r/C_alg`：

| iteration | `u` | stress MPa | residual MPa | tangent MPa |
|---:|---:|---:|---:|---:|
| 0 | 0 | 0 | 260 | 200000 |
| 1 | 0.0013 | 250.476190476 | 9.523809524 | 9523.809523810 |
| 2 | 0.0023 | 260 | 0 | 9523.809523810 |

最终：

```text
u = epsilon = 0.0023
epsilon_p = (260-250)/(1000+9000) = 0.001
alpha = 0.001
X = 9 MPa
```

在塑性区始终使用弹性切线会把修正量压得过小，通常只呈缓慢线性收敛；它不能替代与材料更新一致的算法切线。
