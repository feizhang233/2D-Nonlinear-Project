# V00-V11 Python 演算校验报告

## 1. 演算对象与约定

本报告对应 `验证题目.md` 的 V00-V11。计算由 `04_可复现算例/reference_material_point.py` 完成，并由 `validate_package.py` 复核题答配对、来源编号和数值门槛。

- 语言：Python 3；
- 数值依赖：NumPy；
- 3D convention：3x3 真对称张量，Frobenius 双点积；
- 一维 convention：标量应力、总应变和塑性应变；
- 状态规则：每个方向扰动、局部平面应力迭代和被拒绝试算均从同一 committed state 重算；
- 应力单位：MPa；应变和 `alpha` 无量纲。

### 3.4 失败模式

自动校验另外把 Voce 局部 Newton 和 plane-stress 局部 Newton 的最大迭代数强制设为 1。两条路径均抛出失败，没有返回貌似有效的应力/切线；失败前后的 committed `plastic_strain` 和 `alpha` 逐项相等。

V10 使用独立的 `VoceJ2Parameters`，其字段仅为 `E, nu, sigma_y0, Q, b, H_linear`；线性 J2 的 `H_iso` 不会进入或被静默忽略。
