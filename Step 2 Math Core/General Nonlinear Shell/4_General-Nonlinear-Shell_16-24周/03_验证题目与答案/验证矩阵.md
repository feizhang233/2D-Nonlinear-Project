# General Nonlinear Shell 验证矩阵

## 1. 固定顺序

`旋转群 -> 客观应变 -> 构形转换 -> 完整切线 -> 随动力 -> 厚度/材料 -> 锁死/稳定化 -> 大转动结构 -> 路径跟踪 -> 回滚 -> 综合系统 -> GMNIA 证据`。

前层失败时，后层曲线平滑或 Newton 收敛不能作为补偿。

## 4. 容差规则

- 解析代数题按显示数字的最后 1-2 位设浮点容差；
- 方向差分必须扫描至少 `h=1e-2...1e-8` 的相对步长，不能固定一个魔法数；
- 刚体运动误差按模型长度、刚度和载荷尺度归一化；
- 系统 benchmark 的容差必须来自参考数据精度、数字化误差和网格收敛，不得先定结论再放宽容差；
- 软化、活动集切换和非光滑返回映射可不呈二次收敛，但仍需分段方向差分和状态一致性。

## 5. 自动化元数据

- 软件版本、提交号、线性代数后端和求解器类型；
- 单位、节点/自由度/旋转约定、TL/UL 和残量符号；
- 元素、MITC/假定应变、积分和稳定化；
- 材料、层、厚度点、平面应力局部迭代和状态协议；
- dead/follower 载荷定义、受载面和载荷切线；
- 网格、畸变、边界、缺陷、残余应力和载荷引入；
- 步长、弧长尺度、根选择、容差、失败和回滚；
- 参考值、数字化点集、误差定义和接受结论。
