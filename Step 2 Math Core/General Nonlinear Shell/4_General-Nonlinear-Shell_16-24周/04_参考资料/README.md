## 3. 推荐阅读顺序

1. Chapelle-Bathe 302-308：看非线性壳增量框架、director 和 TL/UL 边界；
2. de Borst 86-118：建立 TL/UL 和材料/几何切线；
3. Bonet 54-138：逐题核对客观性、应力度量、压力和切线；
4. Chapelle-Bathe 262-301：回到壳离散、MITC 和锁死；
5. de Borst 235-267、358-438：接入材料非线性、壳塑性和大应变本构；
6. 两份本地讲义：接入弧长、分岔和 GMNIA 证据链。

## 4. 使用边界

- PDF 页码是文件页码，不一定等于印刷页码；
- 公式落地前回看对应页的符号、构形和假设；
- 图形 benchmark 没有表格数据时，保存数字化点集和坐标标定误差；
- 原书示例是来源，不是当前代码已经通过验证的证据。
