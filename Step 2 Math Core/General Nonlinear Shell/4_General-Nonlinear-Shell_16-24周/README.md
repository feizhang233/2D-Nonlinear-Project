# General Nonlinear Shell 16-24周数学核心引导

## 1. 定位

本目录把当前工作区中与 `08 General Nonlinear Shell` 相关的资料整理为独立专题包。主线是：曲壳几何与 director 有限转动 -> TL/UL 构形 -> 内力、材料/几何/载荷一致切线 -> 厚度积分与材料状态 -> 随动力 -> 锁死与稳定化 -> Newton/弧长 -> 综合验证。

该包面向后续 AI 检索、算法说明、代码评审和测试设计。它是“数学核心与验证规格”，不是已经实现并验证完成的通用壳求解器。

## 2. 已包含

- Reissner-Mindlin/退化连续体型曲壳的中面、director 与厚度坐标；
- `SO(3)` 有限转动增量和客观性要求；
- Total Lagrangian 与 Updated Lagrangian 的一致构形链；
- 内虚功、残量、一致切线及材料/几何/外载切线分解；
- 厚度积分、局部平面应力消元、弹塑性 trial/commit/rollback；
- 随形压力和可能非对称的载荷刚度；
- MITC/假定应变、选择性积分、钻转和零能模态检查；
- 荷载/位移/弧长控制与失稳路径的衔接；
- V00-V14 验证题、配套答案、验收矩阵；
- 可执行的 Python L0 数学核心、26 项自动测试和 V00-V14 分层演算报告；
- 默认 20 周、压缩 16 周、扩展 24 周学习与实现路线；
- 人类可读索引、JSON 索引和 P08 章节路由。

## 3. 明确不包含

- 可直接投入生产的某一种曲壳单元代码；
- 任意材料、任意厚度、任意网格都适用的统一公式或容差；
- 接触、断裂、局部化正则化、疲劳或概率可靠度；
- 完整非线性动力学；动力只在 24 周扩展路线中作为接口预留；
- 规范承载力、折减系数或实验标定；
- 仅凭一条收敛曲线即可成立的 GMNIA 工程结论。
