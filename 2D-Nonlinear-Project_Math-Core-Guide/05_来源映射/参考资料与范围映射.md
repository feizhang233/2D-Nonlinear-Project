# 参考资料与范围映射

## 1. 项目范围来源

当前工作区没有名为 `2D-Nonlinear-Project` 的现成子目录。根据用户目标和已有项目章节映射，本资料包采用：

- 项目显示名：`2D-Nonlinear-Project`；
- 项目路线 ID：`P05`；
- 项目路线名：`Nonlinear Solver / 通用非线性求解器`；
- 目标宿主：二维连续体、框架或壳等能够返回内力、一致切线和试算状态的有限元模型。

这个映射避免把后续 `P08 General Nonlinear Shell` 的完整曲壳、有限转动和材料非线性内容提前混入求解器核心。

## 3. 本次新整理内容

- 求解器级规范残量、切线和实现顺序；
- 2D 有限变形的最小接口桥接；
- 状态试算/提交/回滚协议；
- 荷载、位移、线搜索和弧长控制；
- 算法局限、决策门槛和升级顺序；
- V00-V09 验证题、配套答案和分层矩阵；
- 人类可读与机器可读索引；
- 两本核心参考书的稳定命名副本。

其中 V01、V02、V05-V08 的数值小题是为本项目新构造的最小回归问题；V03、V04 的模型来自 Bonet 等第 1 章并重新独立计算。

## 4. 明确排除

- P02 二维线性连续体的完整单元推导；
- P06 板壳线性屈曲特征值流程；
- P07 壳失稳专题；
- P08 通用非线性壳的曲面几何、有限转动和厚度积分；
- de Borst 书中完整材料、接触、动力和网格正则化内容；
- Bonet 书中未进入 P05 路线的全部连续体本构例题；
- 临时 PDF 提取文本、渲染 PNG 和构建缓存。

## 5. 追溯规则

1. 精简文件是项目级规范，原书用于核对推导和扩展；
2. 任何公式复用必须记录来源章节、PDF 页、符号映射和适用范围；
3. 若代码已有相反残量符号，只允许整体映射，不允许只改 Newton 方程一侧；
4. 若切线依赖状态，方向差分的正负扰动必须从同一 committed state 重算；
5. 新增 benchmark 必须有题目、答案或判定标准，不能只有模型截图；
6. 不能把原书存在某算法当作当前代码已经实现的证据。
