# 参考资料阅读导航

## 1. 使用顺序

完整参考书用于核对推导和上下文，不应作为后续 AI 的默认首读材料。推荐顺序：

1. 先读包内 `01_核心算法`、`02_算法局限` 和 `03_验证题目与答案`；
2. 根据 `CONTENT_INDEX.md` 的页码路由打开最小相关章节；
3. 抽取公式时保留原书符号、残量方向、页码和适用条件；
4. 如果原书与包内符号不同，先写完整映射，再进行实现。

## 2. de Borst 等：Non-Linear Finite Element Analysis

文件：`deBorst_et_al_2012_Nonlinear_FEA_2e.pdf`

本包使用范围：

- 第 2 章，PDF 50-81 页：平衡、空间离散、增量-迭代、Newton、荷载/位移控制；
- 第 4 章，PDF 131-159 页：线搜索、弧长、Riks、稳定/唯一性、步长和拟 Newton。

这本书是求解器算法和控制方式的主要参考，不代表本包已经实现书中的材料、接触、动力或所有单元。

## 3. Bonet 等：Worked Examples in Nonlinear Continuum Mechanics

文件：`Bonet_et_al_2012_Worked_Examples_Nonlinear_Continuum.pdf`

本包使用范围：

- 第 1 章，PDF 11-18 页：杆-弹簧 snap-through、不完美柱和 Newton；
- 第 8 章，PDF 111-122 页：内外虚功的方向导数；
- 第 9 章，PDF 123-138 页：离散内力、切线、压力切线和线搜索题。

这本书适合把公式转成最小回归测试。复用例题时应保留几何、参数、符号和页码；不要只复制最终数值。
