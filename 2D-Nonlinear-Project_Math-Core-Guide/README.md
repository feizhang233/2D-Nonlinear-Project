# 2D-Nonlinear-Project 数学核心引导

## 1. 资料包定位

本目录把当前 FEA Document 工作区中与 `P05 Nonlinear Solver` 相关的内容整理成一个独立、可追溯、面向后续 AI 的数学核心资料包。

项目名称采用用户目标 `2D-Nonlinear-Project`；数学范围以现有项目路线中的 P05 为基线：建立可服务于二维连续体、框架或壳模型的准静态非线性求解器，并保持与具体单元和材料解耦。

## 2. 当前包含

- 非线性平衡、残量和一致切线；
- 全 Newton-Raphson 与 modified Newton 的边界；
- 荷载控制、位移控制、线搜索和球形弧长；
- trial/commit/rollback 状态事务；
- 收敛、步长调整、失败回退和诊断输出；
- 面向 2D 有限变形单元的最小接口；
- 10 层验证题，其中 V00-V08 有配套解析/数值答案；
- 两本核心参考书的包内副本与页码级来源映射；
- 人类可读与机器可读内容索引。

## 3. 当前不包含

- 某一个完整的 2D 有限变形单元公式；
- 完整超弹性、塑性、损伤或黏性材料库；
- 接触、动力、局部化正则化和多物理；
- 生产级分岔检测、branch switching 或稳定性证明；
- “所有二维非线性问题均适用”的统一容差。

## 4. 最短读取路径

1. `AGENTS.md`：目录内工作的强制规则；
2. `AI_CONTENT_INDEX.json`：机器路由；
3. `AI_USAGE.md`：符号、接口和禁止推断；
4. `01_核心算法/核心算法与实现顺序.md`：实现主线；
5. `02_算法局限/算法局限与适用边界.md`：模型边界；
6. `03_验证题目与答案/验证矩阵.md`：回归门槛；
7. 需要详细来源时再读取 `05_来源映射/参考资料与范围映射.md` 和对应 PDF 页。

## 6. 完成边界

本次完成的是“数学核心引导和验证设计”，不是求解器代码实现。后续实现时应先固定残量、切线、状态和控制接口，再按验证矩阵逐层开发；不要先堆叠材料或单元功能，再回头补基础验证。
