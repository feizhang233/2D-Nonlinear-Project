# 2D Nonlinear Solver 算法局限与适用边界

## 1. 一句话边界

当前资料包定义的是面向二维有限元模型的准静态非线性求解与状态管理核心；它不是一个已经包含所有二维非线性单元、本构、接触、动力和失稳分支识别能力的完整求解器。

## 2. 能力边界表

| 主题 | 当前支持 | 主要风险 | 何时升级 |
|---|---|---|---|
| 平衡 | 准静态 `r=f_ext-f_int=0` | 真实瞬态 snap-through 被当成静态路径 | 惯性重要时使用隐式/显式动力 |
| 迭代 | 全 Newton，允许 modified Newton | 一致切线错误会失去二次收敛 | 先做方向导数核验，再考虑拟 Newton |
| 控制 | 荷载、位移、基础弧长 | 单一控制量可能无法穿越 snap-back 或局部化 | 使用弧长、局部位移或耗散控制 |
| 线搜索 | 沿 Newton 方向调节步幅 | 不能修复错误残量、错误切线或错误状态 | 先修正数学核心，再调线搜索 |
| 2D 接口 | 可连接 2D continuum/frame/shell | 求解器本身不保证单元客观性和锁死性能 | 为每类单元建立独立 math core 与测试 |
| 几何非线性 | 接受元素返回的有限变形内力/切线 | TL/UL/共回转混用会破坏功共轭 | 固定运动学和应力应变对 |
| 材料非线性 | 接受试算/提交/回滚状态 | 局部积分、算法切线和耗散未由本包规定 | 建立材料点专用验证包 |
| 随形荷载 | 接口允许外力切线 | 忽略外力方向导数会使切线错误或非对称 | 明确实现 follower-load tangent |
| 软化/损伤 | 可迭代但无正则化保证 | 网格依赖、局部化和路径非唯一 | 使用非局部/梯度/裂带/相场等正则化 |
| 分岔 | 可监控切线奇异性 | 弧长不自动选择正确分支 | 增加特征模态、缺陷和 branch switching |
| 约束 | 消元式位移控制 | penalty 过大导致病态，MPC 处理未规定 | 使用拉格朗日乘子/变换/约束预处理 |
| 线性代数 | 允许对称或非对称求解 | 错误假设正定会在极限点失败 | 采用可报告惯性/主元的稳健求解器 |

## 3. 求解器与物理模型不是同一层

一个 Newton 循环收敛，只能证明所提供的离散残量在数值上接近零。它不能自动证明：

- 运动学是客观的；
- 应力与应变功共轭；
- 单元通过 patch test；
- 本构更新满足屈服条件和耗散；
- 网格收敛；
- 得到的是物理上稳定或唯一的平衡分支。

因此必须分别验证求解器层、单元层、材料层和模型层。

## 4. 一致切线的局限

全 Newton 的二次收敛依赖残量可微、切线一致且当前点进入收敛半径。以下情况会破坏预期：

- 材料返回映射使用割线而不是算法切线；
- 几何刚度缺项；
- follower load 外力切线缺项；
- 接触激活/失活导致非光滑；
- 损伤、摩擦或屈服面角点不可微；
- 试算状态在迭代间累积污染；
- 数值积分点或形函数导数不一致。

最低检查是对装配后的内力做方向导数：

$$
\frac{\mathbf f_{int}(\mathbf u+h\mathbf p)
-\mathbf f_{int}(\mathbf u-h\mathbf p)}{2h}
\approx\mathbf K_t\mathbf p.
$$

应使用一组递减的 $h$，寻找截断误差和舍入误差之间的误差谷值；只测一个 $h$ 可能偶然通过。

## 5. 荷载控制的极限点失败

在荷载-位移曲线的水平切线处，荷载控制切线可能奇异。极限点之后，略高的给定荷载可能没有邻近静态平衡解。此时：

- 减小 Newton 容差不会创造不存在的解；
- 线搜索不能改变控制超曲面；
- modified Newton 不能绕过路径表示问题；
- 应改用位移控制或弧长控制。

## 6. 位移控制仍可能失败

位移控制能跨越许多荷载峰值，但如果选定自由度在真实路径上发生反向，固定该位移仍不能追踪 snap-back。控制自由度选择也可能在局部屈曲、对称破缺或多点局部化后失去代表性。

## 7. 弧长法的局限

弧长法不是自动稳定性或分支选择器。主要风险包括：

- 位移与荷载项量纲不同，`beta` 或缩放不合理；
- 二次方程有两个根，错误根会倒退或跳支；
- 强曲率处出现复根或跨越局部细节；
- 分岔点附近存在多条满足约束的路径；
- 全局球形约束不适合高度局部化的裂纹/剪切带过程；
- 热荷载、压力或非比例荷载不能简单写成固定 `lambda*fhat`。

弧长结果必须结合增量方向、步长敏感性、切线特征信息和缺陷敏感性解释。

## 8. 状态管理和路径依赖

材料塑性、损伤、黏性、接触和历史最大值都依赖加载路径。若失败迭代改变 committed state，可能出现：

- 结果依赖最大迭代数；
- 同一总荷载用不同步数得到不同的非物理差异；
- 卸载后残余状态错误；
- 步长回退后仍保留失败步损伤；
- restart 与连续计算不一致。

因此必须有可测试的 trial/commit/rollback 协议和 restart 等价性测试。

## 9. 二维有限变形的几何风险

对于有限变形二维连续体：

- `det(F)<=0` 表示局部反转或退化，通常必须拒绝；
- 近不可压缩材料可能产生体积锁死；
- 低阶全积分与减缩积分分别可能过硬或出现 hourglass；
- 大刚体转动必须保持零应变/零内能；
- plane stress 的有限应变厚度更新需要局部求解，不能直接沿用小应变矩阵；
- plane strain、axisymmetric 和 generalized plane strain 是不同模型，不能仅改标签。

这些内容属于具体元素/本构核心，本求解器包只规定接口和验证门槛。

## 10. 软化、局部化和网格依赖

局部应变软化模型会使边值问题失去良定性，耗散带宽随网格变化。此时即使每一步 Newton 残量很小，荷载-位移曲线、破坏能和裂纹路径仍可能随网格改变。

没有特征长度或能量正则化时，不得声称：

- 峰后曲线已网格客观；
- 局部应变/损伤云图收敛；
- 单一网格给出的破坏能可信。

## 11. 线搜索的边界

对保守光滑系统，势能线搜索有明确的一维极值条件。对非保守 follower load、摩擦接触或不可微材料，可能不存在可用的全局势能。此时应采用基于残量的 merit function，并明确它与真实势能不是同一物理量。

线搜索还可能掩盖切线质量问题：迭代次数下降并不证明切线正确，必须保留方向导数测试。

## 12. 收敛判据与尺度

只使用绝对残量会受单位和模型大小影响；只使用相对残量在外载接近零时会失真；只检查位移修正可能在刚度很大时过早收敛。

风险包括：

- 不同单位制得到不同收敛判断；
- 大模型的欧氏范数随自由度数增长；
- penalty 或 MPC 约束污染全局范数；
- 线性方程未求准但非线性循环误判收敛；
- 位移控制下反力没有纳入检查。

应同时记录尺度化残量、修正、能量指标和线性求解残差，并把自由自由度与约束反力分开。

## 13. 稳定性、唯一性和分岔

`r=0` 是平衡条件，不是稳定性证明。在保守系统中，可以用切线/势能二阶变分的特征信息辅助判断，但：

- 切线零特征值可能对应极限点、分岔、刚体模式或约束错误；
- 非对称系统不能直接套用对称特征值解释；
- 对称模型可能保持在主分支而错过真实屈曲分支；
- 完美模型与带缺陷模型的峰值可能差异很大。

生产级 branch switching 需要临界模态、扰动方向、分支方向选择和独立验证，当前不包含。

## 14. 当前明确不包含

1. 隐式或显式动力、质量、阻尼和时间积分；
2. 接触搜索、摩擦、穿透控制和接触切线；
3. 完整的有限应变 plane-stress 材料库；
4. 塑性、损伤、黏塑性和超弹性公式的规范实现；
5. 非局部、梯度、相场或 cohesive 正则化；
6. 自动分岔检测和生产级 branch switching；
7. 多参数非比例荷载路径；
8. 热-力、流固或其他多物理耦合；
9. 并行装配和大型稀疏求解器性能设计。

## 15. 停止使用当前简化核心的门槛

遇到下列任一情况，应先升级模型或验证体系：

1. 刚体转动产生明显内力或能量；
2. 解析切线与方向差分不一致；
3. 结果依赖失败迭代是否执行过；
4. 荷载控制在极限点附近持续失败；
5. 位移控制无法表示 snap-back；
6. 弧长根选择随微小扰动改变分支；
7. `detF` 接近零或出现负值；
8. 峰后结果随网格显著变化且没有正则化；
9. follower load 存在但外力切线被忽略；
10. 只有最终曲线，没有迭代、步长、回滚和状态记录。

## 16. 建议升级顺序

1. 固定残量符号、约束处理和线性一步恢复；
2. 建立 trial/commit/rollback 和 restart 等价性；
3. 通过装配级方向导数测试确认一致切线；
4. 完成荷载/位移控制和极限点失败对照；
5. 增加线搜索和自适应步长；
6. 增加球形弧长、根连续性和 snap-back 测试；
7. 再按具体项目加入 2D 有限变形单元与材料积分；
8. 最后扩展局部化正则化、接触、分岔切换或动力学。
