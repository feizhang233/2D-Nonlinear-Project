# 面试问答与复习路径

## 1. 90 秒项目介绍

> 我做的是一个面向二维有限元模型的准静态非线性分析框架。核心问题是求结构在每个加载阶段的平衡，即外力与内力相等。项目统一采用外力减内力的残量，并用当前切线刚度做 Newton 修正。与线性分析相比，非线性分析需要把全过程分成增量步，并在每一步反复更新内力和切线。
>
> 软件上，我把求解器和具体单元分开：共同求解器负责荷载、位移或弧长控制，Newton 迭代、步长调整、收敛和失败回退；Frame、Continuum、Plate 和 Shell 模型负责返回各自的内力、一致切线和试算状态。路径相关状态只有在全局收敛后才提交，失败步会回滚。
>
> 我特别重视验证边界。项目用线性一步恢复、方向导数、状态回滚、弧长基准题和四类模型验证来检查不同层次。数值收敛只说明离散平衡方程得到满足，并不自动说明结构稳定、解唯一或网格已经收敛。

说完后停下来，让面试官选择追问求解器、单元、验证或软件架构。

## 2. 高频问题与短回答

### Q1：线性与非线性有限元最根本的区别是什么？

线性问题的刚度和荷载关系通常可以在参考状态一次建立并求解；非线性问题的内力、刚度或外力方向会随位移和历史状态改变，所以要用增量和迭代不断重新建立平衡。

### Q2：残量有什么物理意义？

残量是尚未平衡的节点力。项目采用 $\mathbf r=\mathbf f_{ext}-\mathbf f_{int}$；当自由自由度上的残量接近零时，离散结构达到数值平衡。

### Q3：切线刚度是什么？

它是当前状态附近“内外力不平衡随位移如何变化”的局部线性化。它不是从初始状态一直不变的线性刚度，而是 Newton 迭代用来预测下一次位移修正的局部斜率。

### Q4：为什么 Newton-Raphson 能求非线性平衡？

因为它在当前点用切线把非线性残量局部线性化，解出一个修正量，再在新点重新计算。接近解且切线一致时，通常会很快收敛。

### Q5：Full Newton 和 Modified Newton 有什么区别？

Full Newton 每次迭代更新切线，单次成本高但通常迭代少；Modified Newton 在一步内复用切线，组装成本低，但通常收敛更慢。选择取决于组装成本、非线性强度和鲁棒性要求。

### Q6：为什么荷载控制会在极限点失败？

极限点附近，继续增加荷载可能不再存在邻近的平衡状态，切线也可能奇异。此时失败可能是控制参数不能表示路径，不一定是程序错误。

### Q7：位移控制和弧长法解决了什么？

位移控制改用一个代表位移推进，可以越过普通荷载极限点；弧长法同时求位移增量和荷载增量，通过路径长度约束沿平衡曲线前进，更适合荷载下降或复杂转折。

### Q8：为什么 trial / commit / rollback 是数学问题，不只是软件问题？

因为塑性、损伤等路径相关变量代表真实加载历史。若失败迭代污染了历史状态，数值迭代次数会改变物理结果。状态事务保证只有收敛平衡点进入真实历史。

### Q9：怎样检查一致切线？

用方向有限差分近似内力的方向导数，再与 $\mathbf K_t\mathbf p$ 比较。还要扫描几个差分步长，区分大步长的截断误差与小步长的舍入误差。

### Q10：残量很小是否说明结果正确？

不充分。它只说明当前离散方程近似平衡。还要检查修正量、线性求解误差、单元几何、状态更新、步长敏感性、网格敏感性以及控制方式的一致性。

### Q11：弧长法得到的下降段是否证明结构不稳定？

不能。弧长法是在追踪平衡路径。稳定性、分岔和实际支路选择还需要特征值、二阶变分、扰动或专门的分支切换分析。

### Q12：这个项目的贡献应该怎样准确表达？

它的重点是统一和可验证：用一个清晰的残量—切线—状态合同连接四类二维模型，并保留收敛、失败、回滚和验证证据。它不是声称提出了新的 Newton 或弧长理论。

### Q13：目前最重要的局限是什么？

这是准静态、受控范围内的二维非线性框架，不是完整的接触、动力、塑性/损伤、断裂、一般曲壳或自动分支切换求解器；基础弧长实现也限于固定比例机械荷载。

## 3. 面试官继续追问时的回答结构

遇到任何技术问题，可以按以下顺序回答：

1. 先说适用范围：准静态/哪种控制/哪类单元；
2. 再说数学对象：残量、切线、状态变量；
3. 再说算法步骤：预测、修正、收敛、提交或回滚；
4. 给一个验证方法：解析解、方向导数、路径或状态回滚；
5. 最后主动说边界：哪些结论还不能推出。

这个顺序比直接堆公式更能体现研究判断力。

## 6. 最后记住的五句话

1. 平衡就是外力等于内力。
2. 残量说明还差多少力，切线把它换成位移修正。
3. 非线性路径靠增量前进，靠迭代回到平衡。
4. 只有收敛状态才能提交，失败试算必须回滚。
5. 数值收敛不是稳定性、唯一性或网格收敛的证明。
