# 2D 非线性有限元：博士面试快速入口

这组材料的目标不是让你背完整推导，而是让你能够用自己的话回答三个问题：

1. 这个项目在求解什么问题？
2. 从模型输入到得到一条非线性响应路径，中间发生了什么？
3. 为什么这个结果值得相信，又有哪些事情不能从结果中推出？

## 你真正需要掌握的层次

先掌握共同求解器，再选一个单元深入。不要试图同时背完四类单元的全部公式。

```text
第一层：共同逻辑
平衡 → 残量 → 切线 → Newton 修正 → 收敛 → 状态提交

第二层：路径控制
荷载控制 → 位移控制 → 弧长法 → 步长缩减与重试

第三层：单元物理
Frame / Continuum / Plate / Shell 如何从位移得到内力和切线

第四层：可信度
解析解、方向导数、状态回滚、网格/步长/控制方式交叉检查
```

## 面试中的表述边界

推荐说：

> 这个项目把残量、切线、路径控制和状态事务统一在一个准静态非线性求解器中，再由不同二维有限元模型提供内力、一致切线和试算状态。

不要说：

> 这是一个已经解决所有材料非线性、接触、动力、分岔和一般曲壳问题的通用商业求解器。

当前实现有明确边界。弧长法能帮助跟踪极限点附近的平衡路径，但一条收敛曲线本身不等于稳定性证明、分岔识别或自动分支切换。
